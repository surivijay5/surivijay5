## 🔭 What I'm Working On

- 🤖 **Agentic UI architecture**: streaming responses, structured cards, and multi-turn elicitation flows, with clear contracts between UI, host, and backend services.
- ⚡ **Frontend performance and reliability**: long-running browser sessions, polling modernization, event/listener teardown, and memory-retention risk reduction.
- 📄 **Contract workflow products**: contract request and eSignature experiences, including data-heavy tables/grids, deep links, and reusable UI components.
- ✅ **Shift-left quality**: hands-on dev testing backed by automation (Playwright, Bruno, k6) so issues are caught before QA, not after release.

  ## 💡 How I Work

  - **Own the whole problem**: I start at the UI and follow issues across MCP/host, APIs, and data when that's where the fix is.
  - **Design contracts early**: clear interaction and payload contracts up front mean fewer late surprises.
  - **Make quality a habit**: accessibility (keyboard and assistive tech), i18n/theming consistency, and async/unmount safety in every review.
  - **Leave things reusable**: performance-testing guidelines, frontend performance practices, and design/protocol docs that the team can build on.
  - **Share knowledge**: code reviews with real feedback, onboarding guides, and internal talks.
 
    ## 🌱 Currently Deepening

    Agentic AI patterns (MCP, streaming, multi-turn flows), browser performance and memory diagnostics, and end-to-end test automation.
